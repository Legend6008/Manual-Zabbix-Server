    Informe de Hardening — Ubuntu 22.04 LTS¶

    Sistema evaluado: Ubuntu 22.04.1 LTS

    1. Objetivo¶

    Aplicar y documentar medidas básicas de hardening en Ubuntu, reduciendo la superficie de ataque mediante la revisión y el ajuste de la autenticación remota, el firewall, las actualizaciones, las políticas de contraseñas, las cuentas de usuario y los servicios.

    2. Alcance y metodología¶

    El trabajo se realiza por etapas. Antes de cambiar una configuración se releva el estado inicial; luego se aplica una modificación controlada y se verifica su resultado con comandos. Se conservan capturas de pantalla o salidas de terminal como evidencias.

    Precaución operativa: mantener una sesión SSH abierta mientras se endurece el acceso remoto. Si es posible, crear una instantánea de la máquina virtual y confirmar el acceso por consola antes de aplicar cambios que puedan impedir una conexión.

    5. Registro de actividades¶

    5.1 Relevamiento inicial¶

    Comandos ejecutados:

    lsb_release -a
sudo ufw status verbose
sudo systemctl status ssh --no-pager
sudo sshd -T | grep -E '^(permitrootlogin|passwordauthentication|kbdinteractiveauthentication|pubkeyauthentication|maxauthtries|allowusers)'

    Resultados relevantes:

    UFW se encuentra activo. SSH está activo y habilitado. La configuración inicial mostró PermitRootLogin prohibit-password, PasswordAuthentication yes, PubkeyAuthentication yes, MaxAuthTries 6 y KbdInteractiveAuthentication no. El archivo /etc/ssh/sshd_config y el archivo /etc/ssh/sshd_config.d/50-cloud-init.conf contienen directivas PasswordAuthentication yes.

    5.2 Endurecimiento SSH propuesto¶

    Se propuso crear /etc/ssh/sshd_config.d/00-hardening.conf con las siguientes directivas. Esta sección describe el cambio propuesto; marcarlo como aplicado solo después de validar y comprobar que una segunda conexión SSH funciona correctamente.

    Directivas propuestas:

    PermitRootLogin no
PasswordAuthentication no
MaxAuthTries 3

    Validaciones previstas:

    sudo sshd -t
sudo sshd -T | grep -E '^(permitrootlogin|passwordauthentication|maxauthtries)'
sudo systemctl reload ssh
sudo systemctl status ssh --no-pager
