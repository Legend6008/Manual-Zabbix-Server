    Integración de Telegram con Zabbix¶

    1. Introducción¶

    La integración de Telegram con Zabbix permite recibir notificaciones de monitoreo directamente en un chat, facilitando la detección y el seguimiento de incidentes.

    Mediante esta configuración, Zabbix podrá enviar mensajes cuando se produzcan eventos asociados a los equipos, servicios o métricas supervisadas.

    Para establecer la integración se necesitan tres elementos:

    • Bot de Telegram: encargado de enviar los mensajes.
    • Token HTTP API: credencial que permite a Zabbix comunicarse con el bot.
    • Chat ID: identificador del usuario o chat que recibirá las notificaciones.

    2. Crear un bot de Telegram¶

    2.1. Acceder a BotFather¶

    1. Abrir Telegram desde el celular o la computadora.
    2. Utilizar el buscador para localizar @BotFather.
    3. Verificar que se trate de la cuenta oficial. Comprobar la insignia de verificación cuando esté disponible y revisar cuidadosamente el nombre de usuario.

    2.2. Crear el bot¶

    Iniciar una conversación con BotFather y enviar el siguiente comando:

    /newbot

    BotFather solicitará dos datos:

    Nombre del bot

    Ingresar un nombre descriptivo que permita reconocer su función. Por ejemplo:

    Alertas Zabbix

    Nombre de usuario (username)

    Elegir un nombre único que termine obligatoriamente en bot. Por ejemplo:

    alertas_zabbix_mauro_bot

    Si el nombre está disponible, BotFather confirmará la creación del bot y proporcionará el Token HTTP API.

    2.3. Guardar el Token HTTP API¶

    El token es una credencial que permite acceder a la API del bot. Se utilizará posteriormente para configurar el tipo de medio en Zabbix.

    Guardar el token en un lugar seguro y evitar compartirlo en capturas de pantalla, documentación pública o repositorios.

    Seguridad: cualquier persona que obtenga el token podría utilizar el bot. Si se expone accidentalmente, se debe revocar o regenerar mediante BotFather y actualizar la configuración de Zabbix.

    3. Obtener el Chat ID¶

    El Chat ID identifica el destino al que se enviarán las notificaciones.

    3.1. Consultar el identificador¶

    1. Abrir el buscador de Telegram.
    2. Buscar @userinfobot o @myidbot.
    3. Iniciar una conversación con el bot.
    4. Enviar /start o el comando que indique el propio bot, como /getid.
    5. Anotar el número de identificación que devuelve.

    Ejemplo ilustrativo:

    Id: 123456789

    El número anterior es solamente un ejemplo. Se debe utilizar el Chat ID real del destinatario.

    4. Iniciar una conversación con el bot de alertas¶

    Este paso es necesario para que el bot pueda enviar mensajes privados al usuario.

    1. Buscar el bot creado en el apartado 2.
    2. Abrir la conversación.
    3. Pulsar Iniciar o enviar un mensaje, por ejemplo:
    Hola

    Los bots de Telegram no pueden iniciar por sí solos una conversación privada con un usuario que nunca los ha contactado.

    5. Configurar el tipo de medio en Zabbix¶

    Una vez obtenidos el token y el Chat ID, ingresar a la interfaz web de Zabbix con una cuenta que tenga permisos de administración.

    5.1. Acceder a los tipos de medios¶

    En el menú lateral, navegar hasta:

    Alertas → Tipos de medios (Alerts → Media types).

    En algunas versiones o traducciones, la ubicación o el nombre del menú puede variar.

    5.2. Editar el medio Telegram¶

    1. Buscar el tipo de medio llamado Telegram.
    2. Abrirlo para editar su configuración.
    3. Revisar la sección Parámetros.
    4. Localizar el parámetro correspondiente al token.
    5. Reemplazar el valor de ejemplo, como <PLACE TOKEN YOUR>, por el token proporcionado por BotFather.
    6. Comprobar que el tipo de medio esté habilitado.
    7. Pulsar Actualizar para guardar los cambios.

    Zabbix incluye una configuración de Telegram en las versiones que ofrecen este tipo de medio, aunque los parámetros disponibles pueden variar según la versión instalada.

    Importante: si el tipo de medio Telegram no aparece, comprobar la versión de Zabbix y consultar su documentación correspondiente. No se debe asumir que todas las versiones incluyen exactamente la misma configuración.

    6. Asignar Telegram al usuario de Zabbix¶

    Configurar el tipo de medio global no es suficiente. También hay que indicar qué usuario recibirá las notificaciones.

    6.1. Acceder a la configuración del usuario¶

    1. Abrir la configuración de usuarios de Zabbix.
    2. Editar el usuario que recibirá las alertas.
    3. Ingresar en la pestaña Medios (Media).

    6.2. Agregar Telegram¶

    Pulsar Añadir y completar los campos:

    Campo Configuración
    Tipo Telegram
    Enviar a Chat ID numérico del destinatario
    Cuándo está activo 1-7,00:00-24:00 para disponibilidad durante toda la semana
    Utilizar si la gravedad es Seleccionar las severidades que se desean recibir
    Estado Habilitado, si el campo está disponible

    Las severidades habituales incluyen:

    • Information (Información)
    • Warning (Advertencia)
    • Average (Media)
    • High (Alta)
    • Disaster (Desastre)

    Las opciones exactas dependen de la versión y la configuración de Zabbix.

    Una vez completados los campos:

    1. Pulsar Añadir en la ventana emergente.
    2. Volver a la pantalla principal de configuración del usuario.
    3. Pulsar Actualizar para guardar los cambios.

    7. Probar el envío de mensajes¶

    Antes de depender de las alertas automáticas, es recomendable comprobar que la integración funciona.

    7.1. Abrir la prueba del tipo de medio¶

    1. Volver a Alertas → Tipos de medios.
    2. Abrir la configuración de Telegram.
    3. Buscar la opción Probar (Test).
    4. Completar los campos solicitados.

    En una prueba manual, algunas macros pueden no resolverse automáticamente. Si aparecen valores como {ALERT.MESSAGE}, {ALERT.SUBJECT} o {ALERT.SENDTO}, reemplazarlos por valores reales.

    Ejemplo de configuración:

    Campo Valor de prueba
    Message Esta es una prueba de alerta de Zabbix.
    Subject Mensaje de prueba
    To Chat ID numérico real

    Atención: el campo To debe contener el Chat ID del destinatario. Si se deja {ALERT.SENDTO} sin resolver, la prueba podría fallar porque Zabbix no tendrá un destino válido.

    Pulsar el botón de prueba y comprobar si el mensaje llega al chat de Telegram.

    7.2. Confirmar el resultado¶

    Si el mensaje llega correctamente, la comunicación básica entre Zabbix y Telegram funciona.

    Si no llega, debemos revisar:

    • Que el token sea correcto y esté vigente.
    • Que el Chat ID corresponda al destinatario.
    • Que se haya iniciado una conversación con el bot.
    • Que el tipo de medio esté habilitado.
    • Que el servidor de Zabbix tenga conectividad con la API de Telegram.
    • Que los mensajes de error del tipo de medio no indiquen problemas adicionales.
