    Instalación del agente Zabbix en Windows 11 LTSC¶

    1. Objetivo¶

    Instalar y configurar el agente Zabbix en Windows 11 LTSC para permitir que el servidor Zabbix supervise el equipo y recopile métricas del sistema.

    La comunicación se realiza mediante la VPN Tailscale, evitando depender de la dirección IP de la red local.

    2. Descargar el agente¶

    Ingresar al sitio oficial de Zabbix:

    https://www.zabbix.com/download_agents
    Seleccionar una versión compatible con el servidor Zabbix 7.4, el sistema operativo Windows y la arquitectura de 64 bits. Descargar el instalador MSI correspondiente.

    3. Instalar el agente¶

    Ejecutar el instalador descargado y completar la configuración.

    Parámetros principales:

    Parámetro Valor
    Host name agentwin11
    Zabbix server 100.84.117.85
    Listen port 10050
    Server for active checks 100.84.117.85:10051

    Importante: el nombre técnico agentwin11 debe coincidir con el nombre configurado posteriormente en la interfaz web de Zabbix.

    4. Configurar el archivo del agente¶

    Localizar el archivo zabbix_agentd.conf o el archivo de configuración correspondiente a la versión instalada.

    Una ruta habitual es:

    C:\Program Files\Zabbix Agent\zabbix_agentd.conf

    Abrirlo con un editor de texto con permisos de administrador y verificar los parámetros establecidos en la instalación:

    Server=100.84.117.85
ServerActive=100.84.117.85:10051
Hostname=agentwin11
    • Server: dirección del servidor autorizado para realizar comprobaciones pasivas.
    • ServerActive: dirección y puerto del servidor que recibe las solicitudes de comprobaciones activas.
    • Hostname: nombre técnico con el que el equipo se identifica ante Zabbix.

    Guardar los cambios.

    5. Verificar el servicio¶

    Abrir PowerShell como administrador y ejecutar:

    Get-Service *Zabbix*

    Verifica el estado del agente en el host

    Luego verificamos los cambios guardados 

    Get-Content "C:\Program Files\Zabbix Agent\zabbix_agentd.conf" |
>> Select-String "^(Server|ServerActive|Hostname|ListenPort|ListenIP)="

    Nos muestra la direccion IP del servidor con el que se comunicara y el nombre del agente de windows 11 ltsc.

    Este otro comando permite comprobar si el servicio del agente está instalado y conocer su nombre.

    Si el servicio se llama Zabbix Agent, reiniciarlo con:

    Restart-Service "Zabbix Agent"

    Comprobar su estado:

    Get-Service "Zabbix Agent"

    El estado esperado es Running.

    Si el servicio tiene otro nombre, utilizar el que aparezca en el primer comando.

    6. Comprobar la conectividad mediante Tailscale¶

    Ejecutar en PowerShell:

    Test-NetConnection 100.84.117.85 -Port 10051

    Este comando verifica si Windows puede establecer una conexión TCP con el puerto de comprobaciones activas del servidor Zabbix.

    El resultado esperado es:

    TcpTestSucceeded : True

    Si aparece False, revisar el estado de Tailscale, las reglas del firewall y la disponibilidad del puerto 10051 en el servidor.

    7. Registrar el equipo en Zabbix¶

    Ingresar a la interfaz web de Zabbix y crear un nuevo host con los siguientes datos:

    Parámetro Valor
    Host name agentwin11
    Visible name Windows 11 LTSC
    Agent interface IP 100.84.117.85
    Port 10050
    Template Windows by Zabbix agent

    La IP 100.125.186.20 corresponde a la dirección Tailscale del equipo Windows utilizado en este laboratorio.

    Vincular la plantilla compatible con la versión instalada del agente y guardar la configuración.

    8. Verificar la recopilación de métricas¶

    Desde la interfaz web de Zabbix:

    1. Ingresar en Monitoring → Hosts.
    2. Localizar el equipo agentwin11.
    3. Consultar Monitoring → Latest data.
    4. Seleccionar el host Windows 11 LTSC.
    5. Verificar que comiencen a aparecer valores en las métricas disponibles.

    La aparición de datos recientes permite comprobar que el agente está enviando información correctamente.

    9. Consideraciones de seguridad¶

    • Utilizar Tailscale para limitar la exposición del servidor a redes externas.
    • Permitir el puerto TCP 10051 para la comunicación de los agentes activos con el servidor.
    • El puerto TCP 10050 es necesario para las comprobaciones pasivas; no debe exponerse innecesariamente si el laboratorio utiliza únicamente comprobaciones activas.
    • Mantener el agente actualizado y restringir el acceso al servidor según las necesidades del laboratorio.
